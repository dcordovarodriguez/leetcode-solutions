## Approach

Reject negative numbers and numbers ending in zero unless the number itself is zero. Reverse only the second half of the integer, then compare the two halves, ignoring the middle digit for odd-length numbers.

## Complexity

- Time: `0(log x)`
- Space: `O(1)`
